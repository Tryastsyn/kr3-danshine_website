ИИ и машинное обучение

Машинное обучение — это способ научить программу решать задачи на примерах, а не по заранее написанным правилам. ML-инженеры собирают данные, обучают модели и встраивают их в продукты: рекомендации, распознавание лиц и речи, чат-боты.

Python

Язык программирования

Сложность: ■□□ легко

Главный язык машинного обучения: почти все библиотеки для ИИ сделаны для Python.

Пример кода

scores = [72, 85, 90, 64]
average = sum(scores) / len(scores)
print("Средний балл:", average)

NumPy

Библиотека для вычислений

Сложность: ■□□ легко

Быстро считает с большими массивами чисел — на нём построены почти все ML-библиотеки.

Пример кода

import numpy as np

a = np.array([1, 2, 3])
print(a * 10)  # [10 20 30]

pandas

Библиотека для таблиц

Сложность: ■□□ легко

Загружает, чистит и анализирует таблицы с данными, например из Excel или CSV.

Пример кода

import pandas as pd

df = pd.read_csv("students.csv")
print(df["score"].mean())

scikit-learn

Библиотека машинного обучения

Сложность: ■■□ средне

Готовые алгоритмы машинного обучения: классификация, регрессия, кластеризация.

Пример кода

from sklearn.linear_model import LinearRegression

model = LinearRegression()
model.fit([[1], [2], [3]], [10, 20, 30])
print(model.predict([[4]]))  # около 40

PyTorch

Фреймворк для нейросетей

Сложность: ■■■ сложно

Помогает создавать и обучать нейросети: от распознавания картинок до языковых моделей.

Пример кода

import torch
from torch import nn

model = nn.Sequential(
    nn.Linear(10, 32),
    nn.ReLU(),
    nn.Linear(32, 1),
)
print(model(torch.rand(1, 10)))

Jupyter

Интерактивный блокнот

Сложность: ■□□ легко

Блокнот, где код, графики и пояснения лежат рядом. Удобно проводить эксперименты по шагам.

Пример кода

pip install notebook
