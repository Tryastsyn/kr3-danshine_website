Переменные

Переменную создают, просто присвоив ей значение. Тип Python определит сам.

name = "Гость"
age = 18
age = age + 1

Типы данных

Основные типы: строка, целое и дробное число, логическое значение, список и словарь.

text = "Привет"            # str — строка
count = 10                 # int — целое число
price = 99.9               # float — дробное число
is_online = True           # bool — логическое
langs = ["Python", "SQL"]  # list — список
user = {"name": "Гость"}   # dict — словарь

Условия

if, elif и else выбирают, какой код выполнить. Блоки выделяют отступом в 4 пробела.

if age >= 18:
    print("Взрослый")
elif age >= 14:
    print("Подросток")
else:
    print("Ребёнок")

Циклы

for проходит по элементам списка или по числам из range, while повторяет код, пока условие верно.

for lang in langs:
    print(lang)

for i in range(3):
    print("Шаг", i)

n = 3
while n > 0:
    n -= 1

Функции

def создаёт функцию, return возвращает результат.

def greet(name):
    return f"Привет, {name}!"

print(greet("друг"))

Переменные

При создании переменной сначала пишут её тип.

int age = 18;
String name = "Гость";
age = age + 1;

Типы данных

Простые типы: int, double, boolean, char. Строки — тип String.

int count = 10;
double price = 99.9;
boolean isOnline = true;
char grade = 'A';
String text = "Привет";

Условия

if выполняет код, если условие верно, а else — если нет.

if (age >= 18) {
    System.out.println("Взрослый");
} else {
    System.out.println("Подросток");
}

Циклы

for повторяет код нужное число раз, а второй вид for проходит по массиву.

for (int i = 0; i < 3; i++) {
    System.out.println("Шаг " + i);
}

int[] numbers = {1, 2, 3};
for (int n : numbers) {
    System.out.println(n);
}

Методы

Функции в Java называются методами и живут внутри класса. Программа начинается с метода main.

public class Main {
    static int sum(int a, int b) {
        return a + b;
    }

    public static void main(String[] args) {
        System.out.println(sum(2, 3));
    }
}

Переменные

var объявляет переменную, а := внутри функции создаёт её и сразу задаёт значение.

var age int = 18
name := "Гость"
age = age + 1

Типы данных

Основные типы: int, float64, bool, string. Список значений — срез.

var count int = 10
var price float64 = 99.9
var isOnline bool = true
var text string = "Привет"
langs := []string{"Go", "SQL"} // срез

Условия

Условие пишут без круглых скобок, а фигурные скобки обязательны.

if age >= 18 {
    fmt.Println("Взрослый")
} else {
    fmt.Println("Подросток")
}

Циклы

В Go есть только один цикл — for, но он умеет всё. range проходит по срезу.

for i := 0; i < 3; i++ {
    fmt.Println("Шаг", i)
}

for _, lang := range langs {
    fmt.Println(lang)
}

Функции

Типы параметров и результата пишут после имён.

func sum(a int, b int) int {
    return a + b
}

Запуск кода

Node.js выполняет JavaScript вне браузера — на компьютере или сервере.

// файл app.js
console.log("Привет из Node.js!");

// запуск в терминале:
// node app.js

Модули

Код делят на файлы: из одного файла экспортируют функции, в другом подключают их через require.

// math.js
function sum(a, b) {
  return a + b;
}
module.exports = { sum };

// app.js
const { sum } = require("./math");
console.log(sum(2, 3));

Пакеты npm

npm скачивает готовые библиотеки. Список зависимостей проекта хранится в файле package.json.

npm init -y
npm install express

Простой сервер

С библиотекой Express сервер с одним адресом занимает несколько строк.

const express = require("express");
const app = express();

app.get("/", (req, res) => {
  res.send("Привет!");
});

app.listen(3000);

Таблицы

Данные хранятся в таблицах. У каждого столбца есть имя и тип.

CREATE TABLE users (
  id SERIAL PRIMARY KEY,
  name TEXT NOT NULL,
  age INTEGER
);

Добавление данных

INSERT добавляет в таблицу новую строку.

INSERT INTO users (name, age)
VALUES ('Гость', 18);

Выборка

SELECT достаёт данные, WHERE оставляет только нужные строки, ORDER BY сортирует.

SELECT name, age
FROM users
WHERE age >= 18
ORDER BY age DESC;

Изменение и удаление

UPDATE меняет строки, DELETE удаляет. Без WHERE они затронут всю таблицу.

UPDATE users SET age = 19 WHERE id = 1;
DELETE FROM users WHERE id = 1;

Связь таблиц

JOIN соединяет строки двух таблиц по общему полю, например заказы и их покупателей.

SELECT users.name, orders.total
FROM orders
JOIN users ON users.id = orders.user_id;

Образ и контейнер

Образ — шаблон приложения, контейнер — запущенная копия образа. Готовые образы берут с Docker Hub.

docker pull nginx
docker run -d -p 8080:80 nginx

Dockerfile

Рецепт сборки своего образа: на чём основан, какие файлы скопировать, какую команду запустить.

FROM python:3.12-slim
WORKDIR /app
COPY . .
RUN pip install -r requirements.txt
CMD ["python", "app.py"]

Сборка и запуск

build собирает образ из Dockerfile, run запускает контейнер.

docker build -t my-app .
docker run --name my-container -p 8000:8000 my-app

Управление контейнерами

Посмотреть запущенные контейнеры, их логи и остановить.

docker ps
docker logs my-container
docker stop my-container
