DevOps

DevOps-инженер связывает разработку и эксплуатацию. Он настраивает автоматическую сборку, тесты и выкладку приложения на серверы и следит, чтобы сервис работал без сбоев. В DevOps редко приходят с нуля: чаще — из системных администраторов или разработчиков.

Linux

Операционная система

Сложность: ■■□ средне

На Linux работают почти все серверы — DevOps-инженер проводит в его терминале большую часть дня.

Пример кода

systemctl status nginx
df -h

Docker

Контейнеры

Сложность: ■■□ средне

Упаковывает приложение со всеми зависимостями в контейнер, который одинаково запускается везде.

Пример кода

FROM python:3.12-slim
WORKDIR /app
COPY . .
RUN pip install -r requirements.txt
CMD ["python", "app.py"]

GitLab CI/CD

Автоматизация сборки

Сложность: ■■□ средне

Запускает сборку, тесты и выкладку при каждом изменении кода — по шагам из файла .gitlab-ci.yml.

Пример кода

stages:
  - test
  - deploy

test:
  stage: test
  script:
    - pytest

deploy:
  stage: deploy
  script:
    - ./deploy.sh

Kubernetes

Управление контейнерами

Сложность: ■■■ сложно

Запускает и перезапускает сотни контейнеров и распределяет между ними нагрузку.

Пример кода

kubectl get pods
kubectl scale deployment my-app --replicas=3

Terraform

Инфраструктура как код

Сложность: ■■□ средне

Описывает серверы, сети и базы данных в файлах, а потом сам создаёт их в облаке.

Пример кода

resource "aws_instance" "web" {
  ami           = "ami-12345678"
  instance_type = "t3.micro"
}

Prometheus

Мониторинг

Сложность: ■■□ средне

Собирает метрики серверов и приложений: нагрузку, память, число ошибок. По ним строят графики и оповещения.

Пример кода

rate(http_requests_total{status="500"}[5m])
