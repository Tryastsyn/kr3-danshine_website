Материалы

Главные темы по каждому языку и инструменту направления «Мобильная разработка» — коротко и с примерами кода. Нажми на название, чтобы открыть темы.

  • Kotlin
  • Swift
  • Dart
  • Flutter
  • Android Studio
  • Xcode

Переменные

val — значение нельзя изменить, var — можно.

val name = "Гость"  // нельзя изменить
var age = 18        // можно изменить
age += 1

Типы данных

Основные типы: Int, Double, Boolean, String. Список создают через listOf.

val count: Int = 10
val price: Double = 99.9
val isOnline: Boolean = true
val text: String = "Привет"
val apps = listOf("Карты", "Почта")

Условия

Кроме if есть удобный when — выбор из нескольких вариантов.

if (age >= 18) {
    println("Взрослый")
} else {
    println("Подросток")
}

when (age) {
    in 0..13 -> println("Ребёнок")
    else -> println("Не ребёнок")
}

Циклы

for проходит по диапазону чисел или по списку.

for (i in 1..3) {
    println("Шаг $i")
}

for (app in apps) {
    println(app)
}

Функции

fun создаёт функцию. Тип параметра и результата пишут через двоеточие.

fun greet(name: String): String {
    return "Привет, $name!"
}

Переменные

let — константа, var — переменная.

let name = "Гость"  // константа
var age = 18        // переменная
age += 1

Типы данных

Основные типы: Int, Double, Bool, String. Массив пишут в квадратных скобках.

let count: Int = 10
let price: Double = 99.9
let isOnline: Bool = true
let apps: [String] = ["Карты", "Почта"]

Условия

Условие пишут без круглых скобок.

if age >= 18 {
    print("Взрослый")
} else {
    print("Подросток")
}

Циклы

for-in проходит по диапазону чисел или по массиву.

for i in 1...3 {
    print("Шаг \(i)")
}

for app in apps {
    print(app)
}

Функции

func создаёт функцию, тип результата пишут после стрелки ->.

func greet(name: String) -> String {
    return "Привет, \(name)!"
}

print(greet(name: "друг"))

Переменные

var — обычная переменная, final задают один раз, const — значение известно заранее.

var age = 18;
final name = 'Гость';
const maxApps = 10;

Типы данных

Основные типы: int, double, bool, String, список List.

int count = 10;
double price = 99.9;
bool isOnline = true;
String text = 'Привет';
List<String> apps = ['Карты', 'Почта'];

Условия

if выполняет код, если условие верно, а else — если нет.

if (age >= 18) {
  print('Взрослый');
} else {
  print('Подросток');
}

Циклы

Обычный for со счётчиком и for-in для прохода по списку.

for (var i = 1; i <= 3; i++) {
  print('Шаг $i');
}

for (var app in apps) {
  print(app);
}

Функции

Тип результата пишут перед именем функции.

String greet(String name) {
  return 'Привет, $name!';
}

Новый проект

Проект создают и запускают командами в терминале.

flutter create my_app
cd my_app
flutter run

Виджеты

Всё на экране — виджеты: текст, кнопки, отступы, картинки.

const Text(
  'Привет!',
  style: TextStyle(fontSize: 24),
)

Колонки и строки

Column ставит виджеты друг под другом, Row — в ряд.

Column(
  children: [
    const Text('Заголовок'),
    ElevatedButton(
      onPressed: () {},
      child: const Text('Нажми'),
    ),
  ],
)

Состояние

В StatefulWidget данные меняют через setState — и экран перерисовывается.

int count = 0;

ElevatedButton(
  onPressed: () => setState(() => count++),
  child: Text('Нажали $count раз'),
)

Структура проекта

Код на Kotlin лежит в папке kotlin+java, картинки и другие ресурсы — в res, настройки приложения — в AndroidManifest.xml.

app/
├── manifests/AndroidManifest.xml
├── kotlin+java/MainActivity.kt
└── res/
    ├── drawable/
    └── values/

Экран на Jetpack Compose

Новые проекты рисуют экраны функциями с пометкой @Composable.

@Composable
fun Greeting() {
    Text(text = "Привет!")
}

Запуск на эмуляторе

В Device Manager создают виртуальный телефон, а приложение запускают кнопкой Run или сочетанием Ctrl + R на Mac (Shift + F10 на Windows).

Новый проект

File → New → Project → App, в поле Interface выбирают SwiftUI. Xcode работает только на Mac.

Экран на SwiftUI

Экран описывают структурой с полем body. VStack ставит элементы друг под другом.

struct ContentView: View {
    var body: some View {
        VStack {
            Text("Привет!")
            Button("Нажми") {
                print("Нажато")
            }
        }
    }
}

Запуск в симуляторе

Cmd + R собирает приложение и открывает его в симуляторе iPhone прямо на компьютере.
