Общие вопросы

Отталкивайся от того, что хочется создавать. Любишь игры — смотри разработку игр, хочешь своё приложение в телефоне — мобильную разработку, нравятся цифры и таблицы — анализ данных. Когда результат интересен, учиться намного легче.

Если пока ничего не цепляет, начни с фронтенда: результат сразу видно в браузере, а для старта нужен только редактор кода, например VS Code. Подсказки по каждому направлению есть на странице «Как это работает».

Для старта в большинстве направлений хватит школьной математики: арифметики, процентов и логики. Больше всего математики нужно в трёх направлениях:

  • ИИ и машинное обучение — векторы и матрицы, производные, теория вероятностей;
  • Анализ данных — статистика: среднее, медиана, разброс, корреляция;
  • Разработка игр — векторы и тригонометрия для движения, поворотов и физики.

Эти темы не обязательно учить заранее — их удобно подтягивать, когда они встречаются в задачах.

Для фронтенда, бэкенда, анализа данных и DevOps хватит обычного ноутбука, желательно с 8 ГБ оперативной памяти или больше. Но есть исключения:

  • Разработка игр — для Unreal Engine нужен мощный компьютер с хорошей видеокартой, Unity менее требователен;
  • Мобильная разработка — приложения для iPhone собирают в Xcode, а он работает только на macOS. Для Android подойдёт любой компьютер, но эмулятору телефона нужно много памяти;
  • ИИ — большие модели обучают на видеокартах, но для учёбы хватит бесплатного Google Colab, который работает прямо в браузере.

Достаточно уметь читать технический текст со словарём или переводчиком. Этот навык быстро растёт сам по мере учёбы.

Серверную часть пишут на Python, Java, Go, JavaScript (Node.js), C#, PHP и других языках. Для первого языка часто советуют Python: простой синтаксис и много материалов.

Java и C# часто используют в больших компаниях и банках, Go — в сервисах с большой нагрузкой. Главное — выбрать один язык и дойти на нём до своего API с базой данных.

API — это правила, по которым программы общаются друг с другом. Например, приложение погоды отправляет запрос на сервер, а сервер отвечает данными о погоде в формате JSON.

Бэкенд-разработчик как раз пишет такие API: принимает запросы от сайта или приложения, берёт данные из базы, обрабатывает их и отправляет ответ.

Аналитик данных изучает данные и отвечает на вопросы бизнеса: почему упали продажи, какой товар покупают чаще. Результат его работы — отчёты, графики и выводы.

Специалист по машинному обучению создаёт модели, которые сами делают прогнозы: рекомендуют фильмы, распознают лица, переводят текст. Направления близки — в обоих используют Python и pandas, поэтому из анализа данных часто переходят в ИИ.

Kotlin — основной язык для Android, Swift — для iPhone. На них приложение пишут отдельно для каждой системы, зато оно работает быстро и может использовать все возможности телефона.

Flutter (язык Dart) позволяет написать одно приложение сразу для Android и iOS. Если у тебя нет Mac, начни с Kotlin или Flutter: для Swift нужен Xcode, а он работает только на macOS.

Для учёбы публиковать ничего не нужно: приложение можно запускать в эмуляторе на компьютере или прямо на своём телефоне.

Да, SQL — главный инструмент аналитика. Данные компаний хранятся в базах, и чтобы их достать, нужно написать SQL-запрос: выбрать нужные столбцы, отфильтровать строки, посчитать суммы.

Python с pandas нужен уже потом — чтобы обработать данные, построить графики и найти закономерности. Обычно учат оба, и начинать удобно с SQL: он проще.

Получает вопрос от коллег, например: «Почему в марте упали продажи?». Дальше достаёт данные из базы через SQL, чистит их от ошибок и пропусков, считает показатели и строит графики.

В конце аналитик объясняет вывод простыми словами и советует, что делать. Поэтому кроме техники здесь важно умение понятно рассказывать о результатах.

Взламывать чужие сайты и устройства без разрешения владельца нельзя — это уголовное преступление. Специалисты по безопасности проверяют системы только по договору с компанией.

Чтобы защищать системы, нужно понимать, как они устроены. Поэтому сначала изучают основы: как работают компьютерные сети, командную строку Linux и один язык для скриптов — Python или Bash.

После этого переходят к самой безопасности: типичным уязвимостям сайтов, инструментам Kali Linux и задачам CTF. Эта база нужна и тем, кто защищает системы, и тем, кто ищет в них уязвимости.

Можно, но это сложнее, чем в других направлениях. DevOps-инженер связывает разработку и серверы, поэтому ему нужно понимать и то, и другое. Часто в DevOps приходят из системного администрирования или из бэкенда.

Если начинаешь с нуля, иди по шагам: Linux и командная строка → сети → Git → Docker → CI/CD → Kubernetes и облака.

Docker упаковывает программу вместе со всем, что ей нужно для работы: нужной версией языка, библиотеками и настройками. Такая «коробка» называется контейнером.

Контейнер одинаково запускается на ноутбуке разработчика, на тестовом сервере и в облаке. Так пропадает проблема «а у меня на компьютере всё работало».
