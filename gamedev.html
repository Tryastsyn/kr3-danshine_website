Разработка игр

Разработка игр — это создание компьютерных, мобильных и консольных игр. Программист игр пишет игровую логику: управление персонажем, физику, поведение врагов, интерфейс и сохранения, а игровой движок помогает собрать всё это в готовую игру.

C#

Язык программирования

Сложность: ■■□ средне

Основной язык движка Unity. На нём пишут поведение персонажей, управление и правила игры.

Пример кода

using UnityEngine;

public class Player : MonoBehaviour
{
    public float speed = 5f;

    void Update()
    {
        float x = Input.GetAxis("Horizontal");
        transform.Translate(x * speed * Time.deltaTime, 0, 0);
    }
}

Unity

Игровой движок

Сложность: ■□□ легко

Популярный движок для 2D- и 3D-игр. Сцены собирают в редакторе, а поведение объектов пишут на C#.

Пример кода

void Start()
{
    Debug.Log("Игра началась!");
}

Godot

Игровой движок

Сложность: ■□□ легко

Бесплатный движок с открытым кодом. Его язык GDScript похож на Python и легко даётся новичкам.

Пример кода

extends CharacterBody2D

var speed = 200

func _physics_process(delta):
    velocity.x = Input.get_axis("ui_left", "ui_right") * speed
    move_and_slide()

C++

Язык программирования

Сложность: ■■■ сложно

Быстрый язык, на котором пишут игровые движки и требовательные игры. Основной язык Unreal Engine.

Пример кода

#include <iostream>

int main() {
    int lives = 3;
    std::cout << "Жизней: " << lives << std::endl;
    return 0;
}

Unreal Engine

Игровой движок

Сложность: ■■■ сложно

Движок для игр с реалистичной 3D-графикой. Логику собирают из визуальных блоков Blueprints или пишут на C++.

Пример кода

void AMyCharacter::BeginPlay()
{
    Super::BeginPlay();
    UE_LOG(LogTemp, Warning, TEXT("Игра началась!"));
}

Blender

3D-редактор

Сложность: ■■□ средне

Бесплатная программа для 3D-моделей, анимации и текстур. Для неё можно писать скрипты на Python.

Пример кода

import bpy

bpy.ops.mesh.primitive_cube_add(size=2, location=(0, 0, 0))
