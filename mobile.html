Мобильная разработка

Мобильная разработка — это создание приложений для смартфонов и планшетов на Android и iOS. Мобильный разработчик делает экраны приложения, работу с камерой, картами и уведомлениями, а потом публикует приложение в Google Play и App Store.

Kotlin

Язык программирования

Сложность: ■■□ средне

Основной язык для Android-приложений: код на нём короче, чем на Java, и в нём меньше ошибок с пустыми значениями.

Пример кода

fun main() {
    val name = "Тьмуша"
    println("Привет, $name!")
}

Swift

Язык программирования

Сложность: ■■□ средне

Язык Apple для приложений на iPhone, iPad и Mac.

Пример кода

let name = "Тьмуша"
print("Привет, \(name)!")

Dart

Язык программирования

Сложность: ■□□ легко

Язык, на котором пишут приложения во Flutter. Похож на JavaScript и Java.

Пример кода

void main() {
  var apps = ['Карты', 'Музыка', 'Почта'];
  for (var app in apps) {
    print(app);
  }
}

Flutter

Фреймворк

Сложность: ■■□ средне

Позволяет собрать приложение сразу для Android и iOS из одного кода.

Пример кода

import 'package:flutter/material.dart';

void main() {
  runApp(const MaterialApp(
    home: Scaffold(
      body: Center(child: Text('Привет!')),
    ),
  ));
}

Android Studio

Среда разработки

Сложность: ■□□ легко

Официальная программа для Android-приложений: редактор кода, конструктор экранов и эмулятор телефона.

Пример кода

<TextView
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:text="Привет!" />

Xcode

Среда разработки

Сложность: ■□□ легко

Программа Apple для создания приложений под iPhone. Работает только на Mac.

Пример кода

import SwiftUI

struct ContentView: View {
    var body: some View {
        Text("Привет!")
    }
}
