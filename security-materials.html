Навигация

pwd показывает, где ты находишься, ls — что лежит в папке, cd — переходит в другую папку.

pwd
ls -la
cd /var/log

Файлы

Команды для просмотра, копирования, переименования и удаления файлов.

cat notes.txt
cp notes.txt backup.txt
mv backup.txt old.txt
rm old.txt

Права доступа

У каждого файла есть права: кто может читать, менять и запускать. chmod их меняет.

ls -l script.sh
chmod +x script.sh

Пользователи и sudo

whoami показывает текущего пользователя, sudo выполняет команду с правами администратора.

whoami
sudo apt update

Переменные

Значение присваивают без пробелов вокруг =, а читают через $.

name="Гость"
echo "Привет, $name"

Условия

В квадратных скобках пишут проверку, например есть ли файл.

if [ -f "/etc/passwd" ]; then
  echo "Файл есть"
fi

Циклы

for проходит по списку файлов или слов.

for file in *.log; do
  echo "$file"
done

Конвейеры

Знак | передаёт результат одной команды в другую. Здесь считаем неудачные попытки входа.

grep "Failed password" /var/log/auth.log | wc -l

Переменные

Переменную создают, просто присвоив ей значение. Тип Python определит сам.

name = "Гость"
age = 18
age = age + 1

Типы данных

Основные типы: строка, целое и дробное число, логическое значение, список и словарь.

text = "Привет"            # str — строка
count = 10                 # int — целое число
price = 99.9               # float — дробное число
is_online = True           # bool — логическое
langs = ["Python", "SQL"]  # list — список
user = {"name": "Гость"}   # dict — словарь

Условия

if, elif и else выбирают, какой код выполнить. Блоки выделяют отступом в 4 пробела.

if age >= 18:
    print("Взрослый")
elif age >= 14:
    print("Подросток")
else:
    print("Ребёнок")

Циклы

for проходит по элементам списка или по числам из range, while повторяет код, пока условие верно.

for lang in langs:
    print(lang)

for i in range(3):
    print("Шаг", i)

n = 3
while n > 0:
    n -= 1

Функции

def создаёт функцию, return возвращает результат.

def greet(name):
    return f"Привет, {name}!"

print(greet("друг"))

Правила

Инструменты Kali можно использовать только на своих устройствах или по письменному разрешению владельца — иначе это незаконно.

Сканирование портов

Nmap показывает, какие порты открыты и какие программы на них работают. Пробовать — на своём компьютере.

nmap -sV 127.0.0.1

Учебный стенд

Тренируются на специально уязвимых учебных приложениях, например OWASP Juice Shop, запущенном в Docker.

docker run -d -p 3000:3000 bkimminich/juice-shop

XSS

Если вставить текст пользователя как HTML, в нём может оказаться чужой скрипт. Безопасно — вставлять как текст.

// Опасно: текст станет HTML-кодом
div.innerHTML = userInput;

// Безопасно: текст останется текстом
div.textContent = userInput;

Куки

Скрипт на странице может прочитать куки, если у них нет флага HttpOnly. Поэтому важные куки так защищают.

console.log(document.cookie);

Проверка ввода

Данным от пользователя нельзя доверять: их проверяют и на странице, и обязательно на сервере.

const age = Number(input.value);

if (!Number.isInteger(age) || age < 0) {
  alert("Введите корректный возраст");
}

Переменные и типы

Тип пишут перед именем: int — целое, float — дробное, char — символ.

int age = 18;
float price = 99.9f;
char grade = 'A';

Указатели

Указатель хранит адрес ячейки памяти. & берёт адрес, * читает значение по адресу.

int x = 10;
int *p = &x;
printf("%d\n", *p);  // 10

Массивы и строки

Строка в C — массив символов фиксированного размера. fgets не даст записать больше, чем влезает.

char name[16];
fgets(name, sizeof(name), stdin);

Переполнение буфера

Если записать в массив больше, чем он вмещает, данные испортят соседнюю память. Так появляются уязвимости.

char buf[8];
strcpy(buf, "очень длинная строка");  // опасно!
