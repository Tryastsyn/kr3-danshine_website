Выборка

SELECT достаёт данные, WHERE оставляет только нужные строки, ORDER BY сортирует.

SELECT name, age
FROM users
WHERE age >= 18
ORDER BY age DESC;

Первые строки

LIMIT ограничивает число строк в ответе — удобно посмотреть, что лежит в таблице.

SELECT *
FROM orders
LIMIT 10;

Подсчёты

Функции COUNT, SUM и AVG считают количество, сумму и среднее.

SELECT COUNT(*)   AS orders_count,
       SUM(total) AS revenue,
       AVG(total) AS avg_check
FROM orders;

Группировка

GROUP BY собирает строки в группы и считает итоги по каждой.

SELECT city, COUNT(*) AS orders_count
FROM orders
GROUP BY city
ORDER BY orders_count DESC;

Связь таблиц

JOIN соединяет строки двух таблиц по общему полю, например заказы и их покупателей.

SELECT users.name, orders.total
FROM orders
JOIN users ON users.id = orders.user_id;

Переменные

Переменную создают, просто присвоив ей значение. Тип Python определит сам.

name = "Гость"
age = 18
age = age + 1

Типы данных

Основные типы: строка, целое и дробное число, логическое значение, список и словарь.

text = "Привет"            # str — строка
count = 10                 # int — целое число
price = 99.9               # float — дробное число
is_online = True           # bool — логическое
langs = ["Python", "SQL"]  # list — список
user = {"name": "Гость"}   # dict — словарь

Условия

if, elif и else выбирают, какой код выполнить. Блоки выделяют отступом в 4 пробела.

if age >= 18:
    print("Взрослый")
elif age >= 14:
    print("Подросток")
else:
    print("Ребёнок")

Циклы

for проходит по элементам списка или по числам из range, while повторяет код, пока условие верно.

for lang in langs:
    print(lang)

for i in range(3):
    print("Шаг", i)

n = 3
while n > 0:
    n -= 1

Функции

def создаёт функцию, return возвращает результат.

def greet(name):
    return f"Привет, {name}!"

print(greet("друг"))

Таблица DataFrame

Главный объект pandas — таблица со строками и именованными столбцами.

import pandas as pd

df = pd.DataFrame({
    "city": ["Москва", "Казань"],
    "score": [90, 75],
})

Загрузка данных

Таблицу можно прочитать из CSV или Excel. head() показывает первые строки.

df = pd.read_csv("data.csv")
print(df.head())

Фильтрация

В квадратных скобках пишут условие — останутся только подходящие строки.

good = df[df["score"] > 80]

Группировка

groupby считает итоги по группам, например средний балл по каждому городу.

print(df.groupby("city")["score"].mean())

Массивы

Главный объект NumPy — массив чисел. Он хранит данные компактно и считает очень быстро.

import numpy as np

a = np.array([1, 2, 3])
print(a.shape)  # (3,)

Действия над всем массивом

Операции применяются сразу ко всем элементам, без циклов.

print(a * 2)  # [2 4 6]
print(a + a)  # [2 4 6]

Матрицы

Двумерный массив — это матрица. .T транспонирует её, а @ перемножает матрицы.

m = np.array([[1, 2], [3, 4]])
print(m.T)
print(m @ m)

Статистика

Готовые функции для среднего, максимума и разброса значений.

data = np.array([10, 20, 30, 40])
print(data.mean(), data.max(), data.std())

Линейный график

plot рисует линию по точкам — так показывают изменения во времени.

import matplotlib.pyplot as plt

plt.plot([1, 2, 3, 4], [10, 15, 8, 20])
plt.show()

Столбчатая диаграмма

bar рисует столбцы — удобно сравнивать значения между собой.

plt.bar(["Янв", "Фев", "Мар"], [120, 150, 90])
plt.show()

Подписи

Заголовок и подписи осей делают график понятным без пояснений.

plt.title("Продажи")
plt.xlabel("Месяц")
plt.ylabel("Выручка")

Установка и запуск

Блокнот ставят через pip и открывают в браузере одной командой.

pip install notebook
jupyter notebook

Ячейки

Блокнот состоит из ячеек с кодом и текстом. Ячейку запускают сочетанием Shift + Enter, а результат последней строки появляется под ней.

x = 5
x * 2  # под ячейкой появится 10

Графики в блокноте

Графики Matplotlib рисуются прямо под ячейкой — удобно смотреть данные по шагам.

import matplotlib.pyplot as plt

plt.plot([1, 2, 3], [2, 4, 1])
plt.show()
