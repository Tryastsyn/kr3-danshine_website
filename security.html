Кибер­безопасность

Linux

Операционная система

Сложность: ■■□ средне

На Linux работает большинство серверов, поэтому безопаснику важно уверенно работать в его терминале.

Пример кода

ls -la /etc
sudo tail -f /var/log/auth.log

Bash

Командная оболочка

Сложность: ■□□ легко

Язык команд терминала: на нём автоматизируют проверки и разбор логов.

Пример кода

grep "Failed password" /var/log/auth.log | wc -l

Python

Язык программирования

Сложность: ■□□ легко

На нём пишут свои инструменты: проверку портов, разбор логов, автоматизацию проверок.

Пример кода

import socket

s = socket.socket()
s.settimeout(1)
result = s.connect_ex(("127.0.0.1", 80))
print("Порт открыт" if result == 0 else "Порт закрыт")

Kali Linux

Linux для проверки защиты

Сложность: ■■□ средне

Сборка Linux с сотнями готовых инструментов: Nmap, Wireshark, Burp Suite. Проверять можно только свои системы или по договору с владельцем.

Пример кода

nmap -sV 127.0.0.1

JavaScript

Язык веба

Сложность: ■■□ средне

Нужен, чтобы понимать атаки на сайты — например, XSS, когда на страницу подсовывают чужой скрипт.

Пример кода

// Опасно: текст пользователя станет HTML-кодом
div.innerHTML = userInput;

// Безопасно: текст останется текстом
div.textContent = userInput;

C

Язык программирования

Сложность: ■■■ сложно

Показывает, как программа работает с памятью. Без этого не разобраться в уязвимостях вроде переполнения буфера.

Пример кода

#include <stdio.h>

int main(void) {
    char name[16];
    // fgets не даст ввести больше, чем влезет в массив
    fgets(name, sizeof(name), stdin);
    printf("Привет, %s", name);
    return 0;
}
