Материалы

Главные темы по каждому языку и инструменту направления «ИИ и машинное обучение» — коротко и с примерами кода. Нажми на название, чтобы открыть темы.

  • Python
  • NumPy
  • pandas
  • scikit-learn

  • Jupyter

Переменные

Переменную создают, просто присвоив ей значение. Тип Python определит сам.

name = "Гость"
age = 18
age = age + 1

Типы данных

Основные типы: строка, целое и дробное число, логическое значение, список и словарь.

text = "Привет"            # str — строка
count = 10                 # int — целое число
price = 99.9               # float — дробное число
is_online = True           # bool — логическое
langs = ["Python", "SQL"]  # list — список
user = {"name": "Гость"}   # dict — словарь

Условия

if, elif и else выбирают, какой код выполнить. Блоки выделяют отступом в 4 пробела.

if age >= 18:
    print("Взрослый")
elif age >= 14:
    print("Подросток")
else:
    print("Ребёнок")

Циклы

for проходит по элементам списка или по числам из range, while повторяет код, пока условие верно.

for lang in langs:
    print(lang)

for i in range(3):
    print("Шаг", i)

n = 3
while n > 0:
    n -= 1

Функции

def создаёт функцию, return возвращает результат.

def greet(name):
    return f"Привет, {name}!"

print(greet("друг"))

Массивы

Главный объект NumPy — массив чисел. Он хранит данные компактно и считает очень быстро.

import numpy as np

a = np.array([1, 2, 3])
print(a.shape)  # (3,)

Действия над всем массивом

Операции применяются сразу ко всем элементам, без циклов.

print(a * 2)  # [2 4 6]
print(a + a)  # [2 4 6]

Матрицы

Двумерный массив — это матрица. .T транспонирует её, а @ перемножает матрицы.

m = np.array([[1, 2], [3, 4]])
print(m.T)
print(m @ m)

Статистика

Готовые функции для среднего, максимума и разброса значений.

data = np.array([10, 20, 30, 40])
print(data.mean(), data.max(), data.std())

Таблица DataFrame

Главный объект pandas — таблица со строками и именованными столбцами.

import pandas as pd

df = pd.DataFrame({
    "city": ["Москва", "Казань"],
    "score": [90, 75],
})

Загрузка данных

Таблицу можно прочитать из CSV или Excel. head() показывает первые строки.

df = pd.read_csv("data.csv")
print(df.head())

Фильтрация

В квадратных скобках пишут условие — останутся только подходящие строки.

good = df[df["score"] > 80]

Группировка

groupby считает итоги по группам, например средний балл по каждому городу.

print(df.groupby("city")["score"].mean())

Обучающая и тестовая выборка

Данные делят на две части: на одной модель учится, на другой её проверяют.

from sklearn.model_selection import train_test_split

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

Обучение модели

Создают модель и вызывают fit — она ищет закономерности в данных.

from sklearn.tree import DecisionTreeClassifier

model = DecisionTreeClassifier()
model.fit(X_train, y_train)

Предсказание

predict даёт ответы модели для новых данных.

predictions = model.predict(X_test)

Оценка качества

Ответы модели сравнивают с правильными — например, считают долю верных.

from sklearn.metrics import accuracy_score

print(accuracy_score(y_test, predictions))

Тензоры

Тензор — массив чисел, как в NumPy, только его можно считать на видеокарте.

import torch

x = torch.tensor([1.0, 2.0, 3.0])
print(x * 2)

Нейросеть

Нейросеть собирают из слоёв: линейных слоёв и функций активации между ними.

from torch import nn

model = nn.Sequential(
    nn.Linear(10, 32),
    nn.ReLU(),
    nn.Linear(32, 1),
)

Ошибка и оптимизатор

Функция потерь показывает, насколько модель ошибается, а оптимизатор подправляет её веса.

loss_fn = nn.MSELoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)

Цикл обучения

Модель много раз делает предсказание, считает ошибку и исправляет веса.

for epoch in range(100):
    pred = model(X)
    loss = loss_fn(pred, y)
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

Установка и запуск

Блокнот ставят через pip и открывают в браузере одной командой.

pip install notebook
jupyter notebook

Ячейки

Блокнот состоит из ячеек с кодом и текстом. Ячейку запускают сочетанием Shift + Enter, а результат последней строки появляется под ней.

x = 5
x * 2  # под ячейкой появится 10

Графики в блокноте

Графики Matplotlib рисуются прямо под ячейкой — удобно смотреть данные по шагам.

import matplotlib.pyplot as plt

plt.plot([1, 2, 3], [2, 4, 1])
plt.show()
