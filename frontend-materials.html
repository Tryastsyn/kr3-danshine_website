Структура страницы

Каждая страница начинается с <!DOCTYPE html>. В <head> лежат настройки и название вкладки, в <body> — всё, что видно на экране.

<!DOCTYPE html>
<html lang="ru">
<head>
  <title>Моя страница</title>
</head>
<body>
  <h1>Привет!</h1>
</body>
</html>

Заголовки и текст

Заголовки от <h1> до <h6> показывают важность, <p> — обычный абзац, <strong> выделяет важное.

<h1>Главный заголовок</h1>
<h2>Подзаголовок</h2>
<p>Абзац с <strong>важным</strong> словом.</p>

Ссылки и картинки

<a> ведёт на другую страницу по адресу из href. <img> показывает картинку из src, а alt описывает её словами.

<a href="about.html">Обо мне</a>
<img src="images/cat.png" alt="Рыжий кот">

Списки

<ul> — список с точками, <ol> — нумерованный. Каждый пункт пишут в <li>.

<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

Формы

Собирают данные от пользователя: <input> — поле ввода, <label> — подпись к нему, <button> — кнопка.

<form>
  <label for="email">Почта</label>
  <input id="email" type="email">
  <button type="submit">Отправить</button>
</form>

Селекторы

Говорят, к чему применить стиль: к тегу, к классу (через точку) или к элементу с id (через решётку).

p { color: gray; }
.card { border: 2px solid pink; }
#title { font-size: 40px; }

Цвета и шрифты

color — цвет текста, background — фон, font-family и font-size — шрифт и его размер.

body {
  color: #f7f2f5;
  background: #0d0b0e;
  font-family: Arial, sans-serif;
  font-size: 16px;
}

Блочная модель

У каждого элемента есть внутренний отступ padding, рамка border и внешний отступ margin.

.card {
  padding: 20px;
  border: 4px solid #f3d3e3;
  margin-bottom: 16px;
}

Flexbox

Выстраивает элементы в ряд или в колонку и выравнивает их. Включается свойством display: flex.

.menu {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 12px;
}

Тьмушаптивность

Медиазапрос @media меняет стили на узких экранах, например на телефоне.

@media (max-width: 575px) {
  .menu {
    flex-direction: column;
  }
}

Переменные

let — переменная, значение которой можно менять. const — постоянная: её значение задают один раз.

let score = 0;
score = 10;
const city = "Москва";

Типы данных

Основные виды значений: строки, числа, логические значения, массивы и объекты.

const text = "Привет";          // строка
const age = 18;                 // число
const isOnline = true;          // логическое
const langs = ["HTML", "CSS"];  // массив
const user = { name: "Гость" }; // объект

Условия

if выполняет код, только если условие верно, а else — если нет.

if (age >= 18) {
  console.log("Взрослый");
} else {
  console.log("Подросток");
}

Циклы

for повторяет код нужное число раз, а for...of проходит по всем элементам массива.

for (let i = 1; i <= 3; i++) {
  console.log("Шаг " + i);
}

for (const lang of langs) {
  console.log(lang);
}

Функции

Кусок кода с именем, который можно вызывать много раз. return возвращает результат.

function greet(name) {
  return "Привет, " + name + "!";
}

console.log(greet("друг"));

Работа со страницей

JavaScript находит элементы на странице и реагирует на действия пользователя, например на клик.

const button = document.querySelector(".btn");

button.addEventListener("click", () => {
  button.textContent = "Нажато!";
});

Новый репозиторий

Команда git init говорит Git следить за папкой проекта.

git init

Коммит

Снимок изменений с понятным описанием. Сначала файлы добавляют, потом сохраняют коммитом.

git add .
git commit -m "Добавил главную страницу"

Ветки

Отдельная линия работы: можно пробовать новое, не ломая основной код.

git switch -c feature/menu
git switch main

GitHub

push отправляет коммиты в удалённый репозиторий, pull забирает оттуда чужие изменения.

git push -u origin main
git pull

Типы переменных

После имени через двоеточие пишут тип. Если положить значение другого типа, TypeScript покажет ошибку.

let age: number = 18;
let city: string = "Москва";
let isOnline: boolean = true;

Типы в функциях

Указывают, что функция принимает и что возвращает.

function sum(a: number, b: number): number {
  return a + b;
}

Интерфейсы

Описывают форму объекта: какие у него поля и каких они типов.

interface User {
  name: string;
  age: number;
}

const user: User = { name: "Гость", age: 18 };

Объединение типов

Через черту | разрешают значению быть одного из нескольких типов.

let id: number | string;
id = 42;
id = "abc-42";

Компоненты

Интерфейс собирают из функций-компонентов, которые возвращают разметку.

function Hello() {
  return <h1>Привет!</h1>;
}

JSX

Разметка прямо в JavaScript. Значения вставляют в фигурных скобках, а класс пишут как className.

const name = "друг";
const title = <h2 className="title">Привет, {name}!</h2>;

Props

Данные, которые компонент получает снаружи — как атрибуты у тега.

function Card({ title }) {
  return <div className="card">{title}</div>;
}

<Card title="Фронтенд" />

Состояние

Хук useState хранит данные. Когда они меняются, компонент перерисовывается.

const [count, setCount] = useState(0);

События

Обработчики вроде onClick запускают код, когда пользователь что-то делает.

<button onClick={() => setCount(count + 1)}>
  Нажали {count} раз
</button>
