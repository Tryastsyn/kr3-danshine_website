Факты из мира IT

Листай — у меня ещё много фактов!

Первая программистка

Первой программисткой считают Аду Лавлейс. В 1843 году она написала алгоритм для вычислительной машины Чарльза Бэббиджа — задолго до появления компьютеров.

Самый первый баг

В 1947 году в компьютере Mark II нашли настоящего мотылька, который застрял в реле. Его вклеили в журнал с подписью «первый настоящий случай найденного бага».

Python — не змея

Язык Python назван не в честь змеи, а в честь британского комедийного шоу «Летающий цирк Монти Пайтона». Поэтому в примерах кода на Python часто встречаются слова spam и eggs — они из скетча этого шоу.

Язык за 10 дней

Первую версию JavaScript Брендан Эйх написал всего за 10 дней в 1995 году. Сначала язык назывался Mocha, потом LiveScript. Сейчас на нём работает почти каждый сайт.

Первый сайт

Первый в мире сайт создал Тим Бернерс-Ли в 1991 году. На нём объяснялось, что такое Всемирная паутина и как сделать свою страницу. Его копию до сих пор можно открыть по адресу info.cern.ch.

Git за несколько дней

Git написал Линус Торвальдс в 2005 году — за несколько дней, чтобы вести разработку ядра Linux. Торвальдс же создал и сам Linux. Сегодня Git пользуются почти все программисты.
